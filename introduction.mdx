PitPath Chrono gives sim racing organizers a structured REST API to run timed events from end to end. You can create events, register the rigs your drivers use, record lap times per sector, and manage the participants who compete — all through a single versioned API protected by role-based API keys.

## What you can do with Chrono

- **Manage events** — create and configure timed sessions with simulator, car, and track layout associations.
- **Record lap times** — submit lap data with per-sector splits and mark laps as valid or invalid.
- **Register rigs** — link physical sim rigs to your license so Chrono knows which hardware produced each lap.
- **Track participants** — maintain a roster of drivers and associate them with events and lap records.

## Who it's for

Chrono is built for sim racing league organizers, timing software developers, and anyone integrating live or post-session results into their own tooling. Whether you're running a single-round hotlap championship or a multi-round series across several simulators, Chrono gives you the data model and API surface to support it.
