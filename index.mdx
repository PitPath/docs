PitPath Chrono is a REST API service built for sim racing organizers. It manages the full lifecycle of a timed competition — from registering your hardware rigs and setting up events to recording lap times with sector splits and surfacing results. Whether you're running a local hotlap challenge or a multi-round online championship, Chrono gives you the data layer to power it.

## How it works

<Steps>
  <Step title="Get a license and API key">
    A PitPath license is issued to your organization. Use your license file to bootstrap a rig, then create API keys to authenticate your application.
  </Step>
  <Step title="Register your rigs">
    Register each timing rig by its hardware ID and bind it to your license. Rigs are the physical or virtual machines that submit lap data.
  </Step>
  <Step title="Create an event">
    Define an event with a simulator, allowed cars, track layouts, and participating rigs. Events control what's eligible for timing.
  </Step>
  <Step title="Record laps and view results">
    Submit lap records with sector times and total time. Query the laps endpoint to build leaderboards and results pages.
  </Step>
</Steps>
